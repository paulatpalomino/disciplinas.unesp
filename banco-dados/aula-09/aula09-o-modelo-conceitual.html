PARA VOTAR

Onde fica o CRAS novo?

Pergunta 1

A assistência social registra os atendimentos numa tabela única: uma linha por atendimento, com a data, o tipo e, ao lado, o nome, o bairro e o telefone do CRAS. Um CRAS novo foi inaugurado hoje e ainda não atendeu ninguém. Na tabela única, os dados desse CRAS:

  1. não têm um lugar próprio: um CRAS só aparece junto com um atendimento
  2. ficam numa linha com o atendimento em branco, e as contagens continuam certas
  3. entram numa tabela dos CRAS que a planilha cria sozinha
  4. ficam na linha do total geral, reservada para isso

Antes de avançar: se o telefone de uma unidade aparece em três linhas e ele muda, quantas células precisam ser corrigidas?
Caminho: a tabela única · a repetição · o telefone que mudou · a correção pela metade · a unidade sem ordem · a ordem apagada · a causa.  ·  as setas do teclado avançam a animação.

Versão impressa da animação (todos os passos):

  2. A REPETIÇÃO · a UBS Leste aparece em três ordens: região e telefone repetidos três vezes

PARA VOTAR

Atributo ou entidade?

Pergunta 2

Uma secretaria guarda, de cada servidor, o cargo. Ela também precisa guardar, de cada cargo, o salário-base e a carga horária. Nesse modelo, o cargo é:

  1. só um atributo do servidor.
  2. um relacionamento.
  3. a chave do servidor.
  4. uma entidade, ligada ao servidor.
07 · QUANTOS DE CADA LADO

Toda ligação pede duas perguntas

Antes de avançar: uma unidade tem quantas ordens de serviço? E uma ordem de serviço é de quantas unidades?
Caminho: as duas perguntas · um para muitos · muitos para muitos · um para um · o erro de perguntar só de um lado.  ·  as setas do teclado avançam a animação.

Versão impressa da animação (todos os passos):

  1. AS DUAS PERGUNTAS · um A se liga a quantos B?  ·  um B se liga a quantos A?
  2. UNIDADE → ORDEM · uma unidade tem quantas ordens? muitas
  3. ORDEM → UNIDADE · uma ordem é de quantas unidades? uma
  4. UM PARA MUITOS · unidade 1 : N ordem
  5. ORDEM → TÉCNICO · uma ordem tem quantos técnicos? pode ter vários
  6. TÉCNICO → ORDEM · um técnico executa quantas ordens? muitas
  7. MUITOS PARA MUITOS · ordem N : N técnico
  8. UM PARA UM · unidade 1 : 1 direção
  9. O ERRO MAIS COMUM · perguntar só de um lado
  10. PARA QUE SERVE · 1 : N vira uma seta  ·  N : N vira uma tabela do meio
PARA VOTAR

Que tipo de ligação?

Pergunta 3

Cada servidor trabalha em uma secretaria só, e cada secretaria tem muitos servidores. A ligação entre secretaria e servidor é:

  1. um para um (1 : 1)
  2. um para muitos (1 : N)
  3. muitos para muitos (N : N)
  4. não há ligação
08 · A BOA CHAVE

O que identifica sem dar problema

Uma boa chave

Um código próprio

  • não se repete
  • não muda com o tempo
  • nunca fica vazio
Uma chave ruim

O nome

  • nomes mudam: a escola é rebatizada
  • nomes se repetem: duas pessoas, o mesmo nome
  • nomes são digitados de vários jeitos
E o CPF?

Identifica, mas é dado pessoal

  • prefira um código interno, como a matrícula
  • quanto menos tabelas guardarem o CPF, melhor
  • é o cuidado que a LGPD pede

Foi o que a leitura da Aula 8 avisou: com o nome da unidade como chave, basta escrever "UBS - Norte" numa linha e "UBS Norte" em outra para a planilha contar duas unidades.
