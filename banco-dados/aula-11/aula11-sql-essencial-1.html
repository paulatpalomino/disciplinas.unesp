PARA VOTAR

Qual condição?

Pergunta 1 · anote a sua letra e levante a mão

O gestor quer a lista das ordens de elétrica que custaram menos de 500 reais. Qual é a parte do WHERE?

  1. WHERE servico = 'elétrica' OR custo_total < 500
  2. WHERE servico = 'elétrica' AND custo_total < 500
  3. WHERE servico = elétrica AND custo_total < '500'
  4. ORDER BY servico, custo_total

05 · AGRUPAR E RESUMIR

Um número para cada grupo

Antes de avançar: na tabela dinâmica, em qual caixa você colocaria o serviço? E o custo?
Caminho: a pergunta · contar e somar · com filtro · os grupos · o resumo de cada grupo · a consulta · ordenar o resumo · a média · um cuidado · a tabela dinâmica.  ·  as setas do teclado avançam a animação.

Versão impressa da animação (todos os passos):

  1. A PERGUNTA · quanto custou cada tipo de serviço?
  2. UM NÚMERO SÓ · SELECT COUNT(*), SUM(custo_total) FROM ordens;
  3. COM FILTRO · ... WHERE servico = 'pintura';  →  3 ordens, 9.100
  4. OS GRUPOS · GROUP BY servico
  5. O RESUMO DE CADA GRUPO · pintura: 3 ordens, 9.100  ·  telhado: 1 ordem, 2.900
  6. A CONSULTA · SELECT servico, COUNT(*), SUM(custo_total) FROM ordens GROUP BY servico;
  7. ORDENAR O RESUMO · ORDER BY SUM(custo_total) DESC
  8. A MÉDIA · AVG(horas)  →  pintura: (20 + 30 + 10) ÷ 3 = 20
  9. UM CUIDADO · SELECT id_ordem, SUM(custo_total) ... GROUP BY servico
  10. É A TABELA DINÂMICA · Linhas: GROUP BY  ·  Valores: SUM, COUNT, AVG  ·  Filtros: WHERE
PARA VOTAR

Quantas ordens em cada unidade?

Pergunta 2 · anote a sua letra e levante a mão

O gestor quer saber quantas ordens de serviço cada unidade teve. A tabela ordens tem a coluna id_unidade. Qual consulta responde?

  1. SELECT COUNT(*) FROM ordens;
  2. SELECT id_unidade, COUNT(*) FROM ordens GROUP BY id_unidade;
  3. SELECT id_unidade FROM ordens ORDER BY id_unidade;
  4. SELECT id_unidade, COUNT(*) FROM ordens WHERE id_unidade;
06 · CINCO CUIDADOS AO ESCREVER

Onde a consulta costuma falhar

CuidadoCertoErrado
Texto vai entre aspas simplesservico = 'pintura'servico = pintura
Número vai sem aspas, sem ponto de milhar e com ponto decimalcusto_total >= 2500.50custo_total >= 2.500,50
O texto tem de estar escrito igual ao do banco, com acentoservico = 'hidráulica'servico = 'hidraulica'
As datas deste banco são texto, no formato ano-mês-diadata >= '2026-08-01'data >= 01/08/2026
A consulta termina com ponto e vírgulaFROM ordens;

Os nomes das colunas deste banco não têm acento: servico, regiao. Os valores têm: 'hidráulica', 'elétrica'.

Se a consulta falhar, leia a mensagem: ela diz perto de qual palavra está o erro.
