Antes das tabelas, o desenho

O modelo conceitual é um desenho do que a organização quer guardar: as coisas, os dados de cada coisa e as ligações entre elas. Ele sai da leitura atenta de uma descrição.

Situação · valores simulados

A descrição: "A prefeitura mantém unidades, cada uma com nome, região e telefone. Para cada conserto, abre-se uma ordem de serviço, com data e tipo de serviço. Cada ordem é de uma unidade só. Os técnicos da equipe, cada um com matrícula e especialidade, executam as ordens, e uma ordem pode precisar de mais de um técnico." (situação simulada)
