Antes de baixar, leia a ficha da base

Num portal de dados abertos, cada conjunto de dados vem com uma ficha: quem publica, o que é cada linha, que período cobre, em que formato, com que licença. Essas informações sobre os dados se chamam metadados. Ler a ficha é rápido, e evita semanas de trabalho com a base errada.

Situação · valores simulados

Um grupo do Desafio quer saber se a procura pela ouvidoria cresceu de 2021 a 2025, e em que secretaria. Acha uma base num portal municipal. A base e o portal deste exemplo são inventados.
